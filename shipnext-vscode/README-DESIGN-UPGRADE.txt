SHIPNEXT DESIGN UPGRADE

This version keeps the existing website content and interactions. The main changes are visual: typography, card surfaces, borders, shadows, buttons, and a polished navy/blue/cyan palette. The homepage hero image element is changed to a video.

To run:
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. In the terminal run: npm install
4. Then run: npm run dev
5. Add your own MP4 video at public/hero-video.mp4 (create the public folder if needed).

The video filename must be hero-video.mp4. If you do not have the video ready yet, the rest of the website code can still be reviewed, but the hero video area may appear empty until the file is added.
